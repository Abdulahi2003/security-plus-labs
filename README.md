# Security+ Labs

Hands-on labs and exercises completed while studying for the CompTIA Security+ certification.

## Labs

### Healthcare IT Asset Triage

**Tools:** Google Colab, Jupyter Notebook, Python, GitHub

This lab demonstrates an AI-assisted workflow for analyzing a fictional healthcare IT device inventory.

### What I Practiced

- Jupyter notebooks
- Python lists and dictionaries
- Python loops and conditional statements
- Filtering data based on security-related conditions
- Debugging Python errors
- Understanding notebook runtime and state
- Using AI as a learning assistant
- GitHub repositories and commits
- Basic GitHub security practices

### Security Concepts

The notebook uses a fictional device inventory to identify devices that may need attention based on:

- Days since the device was patched
- Whether the device is encrypted

The data used in this lab is fictional and contains no real organizational, patient, or employee information.
